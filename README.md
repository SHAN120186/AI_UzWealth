# UzWealth AI

Расчётный прототип инвестиционного помощника для рынка Узбекистана.

## Текущий статус
Это **прототип**, не готовый production AI-агент. Реализованы интерактивная HTML-демонстрация, тестовый workflow n8n и черновик интеграции с backend. Цены синтетические. FastAPI/LangGraph backend, нейросеть, реальные источники котировок и Telegram Mini App ещё не реализованы.

## Файлы
- `demo/index.html` — автономная демонстрация интерфейса.
- `n8n/uzwealth_f100_tests.json` — импортируемый workflow тестового расчёта F100.
- `n8n/uzwealth_backend_integration.json` — неактивный черновик интеграции.
- `n8n/run_checks.mjs` — офлайн проверки Code-узлов.
- `n8n/README.txt` — подробности тестов и настройки интеграции.
- `docs/UzWealth_AI_Technical_Specification_v1.docx` — техническое задание.
- `tools/build_spec.py` — исходный скрипт генерации ТЗ; требует python-docx и Graphviz, пути вывода из исходной среды нужно адаптировать.

## Запуск демонстрации
Откройте `demo/index.html` в современном браузере. Сервер и API-ключи не требуются. Демонстрация не обращается к production backend.

## Проверки
Требуется Node.js 18+:
```sh
node n8n/run_checks.mjs
```
Проверяются валидный ввод, ошибки ввода, повторные события, баланс до тийина и обработчики интеграции. Это не сквозной тест backend.

## n8n
Импортируйте JSON через Import from File. Оба workflow неактивны.
Для интеграционного workflow сначала реализуйте и разверните backend по ТЗ, задайте HTTPS origin и UUID события, подключите n8n Credential к HTTP-узлам. Секреты в JSON не храните. Дедупликация демо действует только внутри одного запуска.

## Ограничения
Матрица риска и правовые формулировки требуют утверждения перед публичным запуском. Данные и расчёты демонстрационные; автоматическое исполнение сделок отсутствует.
